src.geometor.posamentier.svg¶

Theme-adaptive .euclid-graphic SVG renderer for geometor.posamentier.

Generates publication-grade interactive SVGs from exact symbolic Model constructions, conforming to the PHOTON Publish Book Codex contract (svg.euclid-graphic, #geom-tick-1..3, prefers-color-scheme: dark, 3-vertex <path> segments, and canonical data-ref / data-aliases attributes for geometor_interactive.js).

src.geometor.posamentier.svg.render_model_svg(model: geometor.model.Model, graphic_id: str, title: str, *, golden_points: set[str] | None = None, given_points: set[str] | None = None, golden_segments: list[SvgHighlight] | None = None, extra_segments: list[tuple[str, str, str]] | None = None, golden_circles: set[str] | None = None, width: int = 680, height: int = 480) → str¶

Render a Model as a calibrated .euclid-graphic SVG.

Parameters:

  • model – Exact symbolic geometry model.

  • graphic_id – Identifier placed in data-graphic-id.

  • title – Human-readable title and aria-label.

  • golden_points – Point IDs rendered with a golden halo.

  • given_points – Point IDs styled as base given points.

  • golden_segments – Highlighted golden-major / golden-minor / structural segments.

  • extra_segments – Additional (p1, p2, css_class) segments to draw.

  • golden_circles – Circle IDs styled as golden circles.

  • width – SVG viewport width in pixels.

  • height – SVG viewport height in pixels.

Returns:

Complete <svg class="euclid-graphic" ...>...</svg> markup.
